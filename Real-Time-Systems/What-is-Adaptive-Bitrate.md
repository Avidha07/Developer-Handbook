# 🎵 Adaptive Bitrate Streaming (ABR)

## 📌 What is Adaptive Bitrate?

Adaptive Bitrate Streaming (ABR) is a streaming technique where the quality of audio or video automatically changes according to network speed to ensure smooth playback with minimal buffering.

---

# 🎧 Spotify Example

When your internet becomes weak:

Spotify changes:

```text
320 kbps → 128 kbps
```

This helps reduce:

- Buffering
- Loading time
- Internet usage

But the music keeps playing smoothly.

You may notice:

- Slightly lower sound quality
- But uninterrupted playback

---

# 📺 Netflix / YouTube Example

If your Wi-Fi becomes slow:

```text
1080p → 720p → 480p
```

This is Adaptive Bitrate working in real time.

The app automatically adjusts quality based on network conditions.

### ✅ Result

- Smooth playback
- Less buffering
- Better user experience

# ⚙️ Technical Idea (Easy Explanation)

Streaming platforms keep multiple quality versions of the same media:

- Low Quality
- Medium Quality
- High Quality

The media player continuously checks:

- Internet speed
- Bandwidth
- Buffering status
- Device performance

Then it dynamically switches quality in real time.

### Example

| Internet Speed | Video Quality |
|----------------|---------------|
| Fast Internet  | 1080p         |
| Medium Internet| 720p          |
| Slow Internet  | 480p          |

This process happens automatically without stopping playback.
